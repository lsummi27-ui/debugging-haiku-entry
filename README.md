# Seventeen Syllables of Debugging

Entry for [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) on make.fun.

`main.py` writes one haiku about debugging — three lines in the 5-7-5
syllable shape — to `/output/entry.txt`:

```
Midnight logs scroll past
one red line blinks, then holds still
it was a typo
```

Seventeen syllables, 77 characters. Nothing else is needed.
